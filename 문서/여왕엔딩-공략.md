## 0. 먼저 — 나무위키가 맞았다 (2026-08-29 전면 수정)

나무위키에 이렇게 적혀 있다:

> 사교평가 500 / 전사평가 or 마법평가 400 이상 / 체력·힘·민첩 평균 500 / 지능·마력·정신력 평균 500 /
> 기품·예절·화술 평균 800 / 감수성·매력·센스 평균 500 / 성향 225 이상

**숫자도 맞고, "전부 만족해야 한다"는 해석도 맞다.** (평균 500 = 합계 1500, 평균 800 = 합계 2400)

한동안 이 문서는 "가중 점수 합산제라서 일부만 채워도 최고점이면 이긴다"고 적어놨었는데 — **틀렸다.**

### 실측 검증 (컬렉션 57개 기록 전부)

두 모델을 갤러리에 남은 엔딩 기록 57개에 전부 대조했다:

| 모델 | 실제 엔딩 예측 적중 |
|---|---|
| 최고점이 이긴다 (기존) | **26/57 (46%)** |
| **조건 전부 충족해야 자격** (수정) | **46/57 (81%)** |

**엔딩은 점수 순위표가 아니라 자격 체크리스트다.**
조건을 전부 충족한 엔딩만 후보가 되고, 그 중에서 하나가 나온다 (Weight 높은 쪽이 유력, 81% 적중).

### ⚠️ 정정 — 전사평가·마법평가는 OR다 (2026-08-29)

`EndingStatus` 테이블에 **`OrGroup` 컬럼**이 있는데 처음에 이걸 놓쳤다.
**같은 OrGroup = OR 조건. 하나만 충족해도 점수는 한 번만 들어간다.**

전사평가 400과 마법평가 400은 **둘 다 OrGroup 2**다.
→ 하나만 채우면 100점, **둘 다 채워도 100점 그대로.**
→ 따라서 여왕 최대는 760이 아니라 **660**. 나무위키의 "전사 or 마법" 표기가 맞았다.

게임 전체 `EndingStatus` 178행 중 **같은 OrGroup에 두 행이 들어간 건 여왕의 이 한 곳뿐**이다.
그래서 다른 엔딩 계산에는 영향이 없다.

**실제 여왕 엔딩 기록으로 검증** (컬렉션에 남아있던 과거 회차):

| 성향 ≥ 225 | 300 | ✅ 150 |

→ 실전 지침: **7개를 다 켜는 것을 목표로 하되, 하나쯤 빠져도 가능성이 아주 없진 않다.**
다만 이번 회차처럼 71 부족으로 날아가는 게 훨씬 흔하다.

### 경쟁 엔딩과의 관계 — Weight

자격을 갖춘 엔딩이 여럿이면 **Weight가 높은 쪽**이 나온다 (57회 중 46회 일치).

| 엔딩 | Weight |
|---|---|
| **여왕 / 프린세스** | **50000** |
| 대장군 / 왕궁마법사 / 왕립예술학회장 / 마법검사 / 외교관 | 40000 |
| 대부호 | 40000 |
| 요리사 / 프리마돈나 / 프리마 발레리나 / 가사 전문 업체 사장 | 21000 |
| 일반 직업 엔딩 | 20000 |

여왕은 최상위 Weight라 **자격만 갖추면 웬만해선 여왕이 나온다.**
같은 50000인 프린세스만 주의하면 되는데, 프린세스는 `DemonMale_Proposal_Allow` 이벤트가 조건에 있어서
아가레스 청혼 라인을 안 타면 자동으로 자격이 없다.

**"다른 엔딩을 안 키운다"는 옛 전략은 이제 의미가 없다.**
남이 몇 점이든 상관없고, 오직 **내 7개 그룹을 다 켰는가**만 중요하다.

### ⚠️ 전사평가·마법평가는 여전히 하나만

OrGroup 2 (OR 조건)이라 하나만 채우면 그룹이 켜진다. 둘 다 채워도 자격에는 아무 변화가 없고,
**마법검사**에게 공짜 400점을 주기만 한다 (전사평가 4등급 200 + 마법평가 4등급 200).
마법검사도 Weight 40000이라 여왕보다 낮으니 치명적이진 않지만, 이득이 0이므로 하나만 올린다.

### 목표: 660점 전부 — "현실적 목표 520점"은 폐기

이전 판에 「520점이면 넉넉히 1위」라고 적어놨는데 **완전히 틀린 조언이었다.**
520점은 조건 5개만 켠 상태이고, 나머지 2개가 꺼져 있으면 **자격 자체가 없다.**

**7개 그룹을 전부 켜야 한다:**

| # | 조건 | 난이도 메모 |
|---|---|---|
| 1 | 성향 ≥ 225 | 운명카드 「역사를 잊지 않는다면」이면 300에서 시작 |
| 2 | 사교평가 ≥ 500 | |

## 3. 성향(Alignment)

- 범위 **-300 ~ 300**, 여왕은 **225 이상**에서 150점
- 수업·알바·아이템·식단 어느 것으로도 안 오름 — 데이터 전체에 StatType 13을 건드리는 스케줄/아이템이 **하나도 없음**
- **이벤트 선택지**로만 변동 (계정에 `LawfulPoint` / `ChaoticPoint`로 누적)
- 실전 메모: **기력 관리를 몇 번 해주면 쉽게 올라감**

## 4. 수확제 대회 — 택1 구조

수확제에는 대회 하나만 참가한다 (게임 텍스트: *"대회에 참가하지 않고 수확제를 종료하시겠습니까?"*).

### 각 대회가 보는 수치

대회 선택 화면 설명문 기준.

| 대회 | 설명문 | 실제로 보는 것 |
|---|---|---|
| **무투제** | "검술과 마법을 가리지 않으며 오직 실력만으로 승패를 가른다" | 전투 스탯 + **장비(무기·갑옷) 필요** |
| **요리제** | "조리 실력은 물론, **마법이나 재료 지식**도 결과에 영향을 준다" | **마력 + 지능 + 식당(Job_Restaurant) 등급** |
| **예술제** | "무용이나 가창을 선보이는 예술 무대. 심사위원의 평가로 순위가 결정된다" | 기술 점수 + 예술 점수 (무용 / 미술 부문) |
| **연회** | "우아한 매너와 대화 능력이 좋은 인상을 남기는 열쇠" | 마력 / 예절 / 감수성 / 센스 중 하나가 150 이상 |

큐브 소개 대사도 같은 구분 — *"전사들의 자존심을 건 무투회, **섬세한 마법을 다루는 요리 대회**, 예술가들이 실력을 뽐내는 예술제, 사교력과 언변을 겨루는 연회"*.

**무투제만 장비를 요구한다.** 무기·갑옷이 없으면 참가 시 경고가 뜨고 불리해진다.
초반 자금이 없을 때 무투제로 돈을 벌려다 장비값에 발목 잡히는 구조.

> 요리제에 불 조절 미니게임 텍스트(`Msg_CookingFestivalHelp1~3`, `Festival_Cook_Guide`)가 데이터에는 있으나 **현재 빌드에는 미구현**으로 보임. 패치로 들어오면 스탯이 부족해도 만회할 여지가 생길 수 있음.

### 여왕 관점 선택
- **요리제**: 상대가 제일 약하고 3위(1000G)까지 보상. **1위 시 마법평가 +40** → 마법평가 400 조건에 직결. 장비 불필요
- **예술제**: 2위·3위 모두 1500G로 하방이 가장 두터움. 사교평가도 적립
- **무투제**: 1위 시 전사+마법 동시 40이지만 **3위 보상 없음** = 실패 시 0원. 장비값까지 나가서 리스크 큼
- **연회**: 돈은 안 나오지만 Ep5 필수 관문. 사교평가 500 달성에도 기여

권장: **초반 요리제로 목돈 + 마법평가 → 중반 이후 예술제 → 연회(Ep5)**
