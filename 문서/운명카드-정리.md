# 운명 카드 전체 정리

게임 파일(`Card` / `AdvantageSet` / `Text` 테이블) 직접 추출. 2026-08-29 기준.
**총 59장 — 계정에 이미 전부 보유 중.**

카드는 **해당 엔딩을 한 번 보면** 해금된다. 다음 회차 시작 시 슬롯에 장착해서 쓴다.

## 슬롯 규칙 (게임 화면 확인 완료)

**슬롯은 3개. 타입 1·2·3 전용이 하나씩** — 즉 각 타입에서 한 장씩, 총 3장을 쓴다.

**마왕 카드「규칙을 들이미는 것이냐」는 이 타입 제한을 없앤다.**
대신 마왕 카드가 슬롯 하나를 먹기 때문에 **실제로 쓸 수 있는 카드는 2장으로 줄어든다.**

| | 장착 카드 수 | 제약 |
|---|---|---|
| 기본 | **3장** | 타입 1·2·3에서 각 1장 |
| 마왕 사용 | **2장** | 타입 자유 (같은 타입 2장 가능) |

→ **마왕은 "같은 타입 카드 2장이 꼭 필요할 때"만 이득이다.**
서로 다른 타입 3장으로 커버되는 조합이면 그냥 손해 — 효과 하나를 버리는 셈.

## 5. 기운(Aura) — 시작 능력치 보너스일 뿐

`Aura` 테이블 확인 결과 **성장률 보정은 없다.** 딱 한 번 붙는 초기 스탯.

| 기운 | 컨셉 | 보너스 | 합계 |
|---|---|---|---|
| 엘두르 (Eldur) | 힘과 열정 | 체력 +11, 힘 +9, 민첩 +8 | **28** |
| 뤼오스 (Ljos) | 자연과 마법 | 지능 +16, 마력 +18, 정신력 +19 | **53** |
| **요르드 (Jord)** | 안정성과 인내 | 기품 +18, **예절 +26**, 화술 +21 | **65** |
| 바트나 (Vatn) | 치유와 유연성 | 감수성 +11, 센스 +8, 매력 +9 | **28** |

→ 순수 총량은 **요르드 > 뤼오스 > 엘두르 = 바트나**.
엘두르와 바트나는 28밖에 안 주니, 총량만 보면 손해다.

## 6. 여왕 플로우 전용 세팅 추천

목표가 **여왕 엔딩 점수**가 아니라 **여왕 에피소드 1~7 전부 보기**라는 전제.
관련 문서: 「플로우-에피소드-공략.md」 · 「여왕엔딩-공략.md」

### 무엇을 뚫어야 하는가

| Ep | 게이트 | 필요한 것 |
|---|---|---|
| 1 | 자유활동 — 분쟁 중재 | 자유활동 횟수 |
| 2 | 자동 | — |
| 3 | 자유활동 — 마수 격퇴 | **전투 스탯** (힘·민첩·공격력) |
| 4 | 자동 | — |
| 5 | 수확제 연회 | 린네 해금 = **예절 150** |
| 6 | 성 퀘스트 완료 → 대공 편지 | 퀘스트 소화 |
| 7 | 대공 접견 | **예절 300** (밀카 대공 해금) |

→ **예절 300**과 **전투 스탯**을 한 회차에 같이 만들어야 한다. 이게 이 런의 전부다.

### 기운: **요르드** 추천

예절 +26으로 시작 — 300 게이트를 향한 출발선이 가장 앞이고, 기품·화술까지 붙어서
여왕 엔딩의 `기품+예절+화술 ≥ 2400` 조건(100점)과 방향이 완전히 같다.
전투 스탯은 아래 카드로 메우는 쪽이 싸다.

> 지난 회차의 엘두르 판단이 아쉬웠던 이유가 여기 있다 — 28밖에 안 주면서
> 초반 장비값까지 나가서 두 번 손해였다.

### 추천 조합 — 마왕 없이 3장

세 장이 전부 다른 타입이라 **마왕을 쓸 이유가 없다.** 3장 다 쓰는 게 정답.

| 슬롯 | 카드 | 왜 |
|---|---|---|
| **타입 1** | **완벽한 군림** (여왕) | 성공률 100% 시작. 스케줄 등급이 **누적 성공점수**로 판정되니, 실패가 사라지면 예절 300까지 가는 시간이 통째로 줄어든다 |
| **타입 2** | **공주님과 왕자님** (아가레스) | 성 예절 요구치 **-20%** → 대공 **300 → 240**. Ep7의 벽을 직접 깎는 유일한 카드 |
| **타입 3** | **역사를 잊지 않는다면** (역사학자) | 성향 질서 **300** 시작. `성향 ≥ 225`는 배점 **150점으로 단일 최대**인데 시작부터 충족 |

### 대안 (상황별 교체)

| 바꿀 슬롯 | 대안 | 언제 |
|---|---|---|
| 타입 1 | **후퇴란 없다** (대장군) | Ep3 전투 게이트가 계속 안 뚫릴 때. 체력·힘·민첩 감소 방지 |
| 타입 2 | **제자의 덕목** (검술 사범) | 예절 300을 찍은 뒤 흘리는 게 문제일 때 |
| 타입 3 | **친절한 이웃** (마을주민) | 예법 수업 **+100%**. 예절 300을 가장 빨리 뚫는 길 — 성향 관리를 손으로 할 자신이 있으면 이쪽이 더 빠르다 |
| 타입 3 | **넘치는 매력** (팜므파탈) | 매력 100 시작 → 제스터(매력 50) 접견이 처음부터 열림. 성 NPC 전원 접견 라인 단축 |

### 마왕을 쓸 만한 경우는?

여왕 플로우 런에서는 **없다.** 마왕을 넣으면 위 3장 중 하나를 통째로 버리는데,
셋 다 서로 다른 게이트를 담당하고 있어서 뭘 빼도 그만큼 늦어진다.

마왕이 이득인 건 **한 타입에 결정적인 카드가 두 장 몰려 있을 때**다.
예를 들어 전투 특화 런이라면 타입 1의 **후퇴란 없다** + **검과 마법의 균형**을 동시에 쓸 수 있다.

### 절대 넣지 말 것

| 카드 | 이유 |
|---|---|
| **안취했다고** (바텐더) | 성향 혼돈 시작. 여왕의 150점 조건과 정반대 |
| **몸이 기억하는 손기술** (괴도) | 성향이 계속 혼돈으로 끌려감 |
| **돈이 돈을 벌게 하라** (가사 전문 업체 사장) | 골드가 쌓이면 대부호 Ep가 1010 슬롯을 잡아먹는다 |
| **선결제** (대부호) | 같은 이유로 대부호 라인 자극 |
| **토벌하라!** (수도정예병단) | 조우율 +15%. 필드가 늘면 모험가 Ep가 1010을 가져간다 |

여왕 Ep2·4는 Priority 0이라 웬만해선 밀리지 않지만, **Ep6은 Pri 1**이라
1010 슬롯을 비워두는 게 여전히 유효하다.
