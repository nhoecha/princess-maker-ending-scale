# 플로우 에피소드 공략 (실플레이 검증판)

2026-08-28 기준. 계정 진행도: **플로우 다시보기 119개 중 117개 획득**, 엔딩 57종/64회.
남은 것: **여왕 에피소드 6·7** 뿐. (Ep3은 2026-08-29 이번 회차에서 재획득)

## 1. 트리거 코드 해석 (전부 실플레이로 검증)

| 코드 | 언제 발동 |
|---|---|
| **1017** | 스케줄(수업·알바·자유활동) 수행 직후. 해당 스케줄에 묶인 이벤트만 후보 |
| **1010** | **정기 자동 체크.** 플레이어 선택과 무관하게 때가 되면 발동. 행상인·점술가·장학금·교사방문·청혼이 전부 여기. 다시보기의 `Schedule` 값은 배경일 뿐 조건 아님 |

## 2. ✅ 프리마돈나 Ep2 — 해결

**조건: 음악 수업 누적 횟수뿐.** 등급·스탯·타 직업 경합 전부 무관.

| 음악 횟수 | 결과 |
|---|---|
| 21회 | 없음 |
| **22~25회** | **Ep1 발동** |
| 31 / 32 / 34회 | Ep2 없음 |
| **37회** | **Ep2 발동** ✅ |

→ **Ep1 = 22~25회, Ep2 = 35~37회**
과거 회차에서 못 본 이유: 음악을 31·34회에서 끝내 임계값 미달.

## 3. ✅ 프린세스 Ep1~7 — 전부 해결

**아가레스 호감도와 무관.** 전부 **린네(왕비) + 성 인맥 + 축제** 라인.

| Ep | 트리거 | Pri | 확정 조건 |
|---|---|---|---|
| 1 | 5001 | 1 | **린네 해금(예절 150) 상태에서 예술제 우승.** 우승만으로는 안 됨 — 린네를 만날 수 있어야 함 |
| 2 | 1017 | 2 | 자유활동 (Ep1 이후) |
| 3 | 1010 | 3 | **성 NPC 9명 전원 접견** ← 해금이 아니라 실제 방문 |
| 4 | 5002 | 4 | **수확제 연회 참가** (편지 받은 뒤) |
| 5 | 2012 | 5 | 성에서 린네 재방문 |
| 6 | 1012 | 1 | **성 퀘스트 완료** (특히 대공 퀘스트 `Quest_RegentDeputy_Burden`·`Throne`) |
| 7 | 2012 | 7 | 편지 받은 뒤 **대공 접견** |

### Ep3 — 가장 오래 막혔던 지점
예절 595라 성 NPC 전원 **해금**은 진작 돼 있었는데, **엘리고스(정예기사)와 대마법사를 실제로 찾아가지 않아** 계속 막혔다.
둘을 접견하자마자 편지 도착. 세이브의 NPC 접견 기록(9명 전원)으로 확인됨.

Ep1 대사의 *"때가 되면 내가 부를게"* 가 곧 **왕성 사람들을 두루 알게 되는 것**이었다.

### Ep6 — 두 번째로 오래 막혔던 지점
밀린 성 퀘스트를 전부 완료하자 대공의 편지 도착.
대공 대사 *"그대에 대해 여러모로 들은 바가 많다네"* 와 앞뒤가 맞음.
※ 이 시점 기품+예절+화술 = 2374 (엔딩 조건 2400 미만)이었으므로 **스탯 게이트 아님**.

### Ep7 — Priority 7 (꼴찌)
2012 트리거에 Priority 0짜리가 30개. 완료 대기 퀘스트를 전부 털어야 차례가 온다.
마지막 달에 성 방문으로 획득.

### Ep3 — 전투 게이트 실측 (2026-08-29)

**발동 확인**: 힘 259 · 민첩 256 · 체력 382 · 전사평가 302 (14.87세 / 144턴 / 자유활동 32회).
검술 15회 · 체술 16회로 만든 수치다.

**하한은 모른다.** 안 뜬 회차가 힘 7 / 민첩 0 / 전사평가 5 수준이라 브래킷이 "0~259"나 마찬가지고,
실질적으로 아무것도 좁혀주지 못한다. "이 정도면 확실히 뜬다"는 상한 정보로만 쓸 것.

## 6. 스케줄 등급 시스템

- 등급 표기: **D=1, C=2, B=3, A=4, S=5**
- 판정 기준은 **누적 성공점수** (성공 1회 ≈ 10점), 횟수가 아님
- `Edu_*` 공통 임계값: **42 / 96 / 160 / 234** (점수 단위)
  - A등급(4) = 160pt ≈ 16회
  - S등급(5) = 234pt ≈ 24회
- 알바는 스케줄마다 다름 (예: 가정교사 37/94/181/308, 검문소 42/120/252/450)

`Quest_RAAPresident`(린네 부여) = 미술·음악·무용 전부 A등급.
조건식: `ScheduleGrade(Edu_Art/Music/Dance, >=, 4)`

| 라인 | Pri | 억제 방법 |

※ 여왕 Ep2·Ep4는 Priority 0이라 오히려 유리 — 여왕 회차에선 억제할 필요 없음.

## 8. 알바 선택 — 「경합 회피」는 폐기

이전 판에 "다른 엔딩 점수를 올리지 않는 알바를 고르라"고 적어놨는데, **엔딩이 총점제가 아니라
자격제라는 게 밝혀지면서 의미가 없어졌다.** 남이 몇 점이든 내 조건만 다 켜면 된다.

알바는 이제 **보수와 기력 효율**로만 고르면 된다.

- **식당**: 보수 41로 최고
- **식물원**: 기력 -16으로 효율 최고

자세한 건 「여왕엔딩-공략.md」의 자격 모델 항목 참조.
