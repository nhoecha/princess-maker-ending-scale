# 프메 엔딩 저울

프린세스 메이커 : 예언의 아이들(Princess Maker: Children of Revelation) 세이브 분석기. 지금 끝나면 나올 엔딩과, 목표 엔딩까지 모자란 조건을 보여 준다.
세이브 파일을 읽어 **지금 끝나면 어떤 엔딩이 나오는지, 목표 엔딩까지 무엇이 얼마나 모자란지** 계산합니다.

파이썬 표준 라이브러리만 사용합니다. 별도 라이브러리 설치가 필요 없습니다.

---

## 쓰기 전에

- 한 사람이 자기 플레이에 필요한 만큼만 고쳐 가며 만든 도구다. 쓰기 불편할 수 있고, 계산과 조건에 오류가 있을 수 있다.
- 기준은 정식 출시 1.0 (빌드 25799757) 이다. 게임이 패치되면 맞지 않을 수 있다.
- 세이브를 읽기만 하지만, 쓰기 전에 세이브 폴더를 백업해 두기를 권한다.
- 비공식 팬 제작물이고 게임 제작사와 관계가 없다. 권리자가 요청하면 내린다.
- 수정 요청은 받지 않는다. 자유롭게 포크해서 고쳐 쓰면 된다.

## 설치

### 1. 파이썬 (한 번만)

이미 설치돼 있으면 건너뛰세요. 확인하려면 터미널에서 `py --version` 을 쳐보면 됩니다.

**시작 메뉴 → `터미널`** (또는 `명령 프롬프트`) 을 열고 아래 한 줄을 붙여넣습니다.

```
winget install -e --id Python.Python.3.12
```

winget은 윈도우에 기본으로 들어 있어 따로 받을 것이 없습니다.
설치가 끝나면 **터미널 창을 닫았다가 새로 열어야** PATH가 적용됩니다.

<details>
<summary>winget이 안 될 때 — python.org에서 직접 설치</summary>

[python.org/downloads](https://www.python.org/downloads/) 에서 Windows 설치 파일을 받습니다.

설치 첫 화면 아래쪽의 **「Add python.exe to PATH」 체크박스를 반드시 켜세요.**
이걸 놓치면 `Python not found` 가 계속 뜹니다. 이미 그렇게 설치했다면
설치 파일을 다시 실행해 `Modify` → `Add to PATH` 를 켜면 됩니다.

</details>

버전은 3.8 이상이면 무엇이든 괜찮습니다. 추가 라이브러리는 필요 없습니다.

### 2. 이 폴더

압축을 풀어 아무 데나 두면 됩니다. 세이브 폴더는 프로그램이 알아서 찾으므로
위치는 상관없습니다.

```
프메분석\
    pmk.py       본체
    run.bat      실행 (이것을 더블클릭)
    README.md    이 문서
```

## 실행

`run.bat` 더블클릭. 세이브 폴더는 자동으로 찾습니다.

**창을 열어둔 채로 게임을 하세요.** 세이브가 갱신되면 자동으로 다시 분석해서
화면을 새로 그립니다. 매 턴 프로그램을 다시 켤 필요가 없습니다.

```
─ 세이브가 갱신되면 자동으로 다시 분석합니다.   [아무 키] 지금 새로고침   [Q] 종료 ─
```

아무 키나 누르면 즉시 새로고침, `Q` 로 종료합니다.
항상 **가장 최근에 저장된 `slot_*.sav`** 를 읽으므로 오토세이브를 그대로 따라갑니다.

### 옵션 (터미널에서)

```
cd "<이 폴더의 경로>"

run.bat                      최신 세이브 · 여왕 기준
run.bat --target 프린세스     목표 엔딩 바꾸기
run.bat account              계정 전체 진행도 (미획득 에피소드·엔딩)
run.bat slot_10              특정 슬롯 지정
run.bat --list               세이브 목록 + 저장 시각
run.bat --endings            엔딩 이름 전체 목록
run.bat --steamid <ID>       Steam64 ID 직접 지정 (보통 불필요)
run.bat --once               한 번만 출력하고 종료 (자동 새로고침 끔)
run.bat --flow               목표 엔딩의 플로우 에피소드 체인만 크게 보기
```

바로가기를 만들어 **대상** 뒤에 옵션을 붙여두면 더블클릭만으로 쓸 수 있습니다.

```
"<이 폴더의 경로>\run.bat" --target 프린세스
```

## 화면 보는 법

### 현재 상태
게임 내 날짜, 딸 나이, 사용한 턴 수, 기력, 성향.

### 지금 끝나면 → OO 엔딩
지금 상태로 게임이 끝났을 때 나올 것으로 예측하는 엔딩. 조건을 전부 충족한 엔딩 가운데 Weight가 가장 높은 것을 고릅니다. 목표와 다르면 빨간색이고, 조건을 전부 충족한 엔딩이 없으면 없다고 나옵니다.

### 목표 엔딩 진단
조건별 충족 여부와 **부족량**. 맨 위에 조건 그룹을 몇 개 채웠는지와 남은 조건을 먼저 보여 주고, 그 아래에 조건별 표가 나옵니다.

**배점은 참고용입니다.** 하나라도 미달이면 그 엔딩은 나오지 않습니다.

```
  ✓ 성향 ≥ 225                150  300     225     —
  ✗ 사교평가 ≥ 500            100  300     500     200
```
왼쪽부터 조건 / 배점 / 현재값 / 목표값 / 부족량.

`?` 표시는 **미확인** — 소지금·필드 클리어·일부 특수 조건은 세이브만으로 판정할 수 없습니다.

**「또는」이 붙은 줄은 OR 조건입니다.**

```
  ✗ 전사평가 ≥ 400            100  302     400     98
  ✗ 마법평가 ≥ 400           또는  60      400     340
    ↑ 둘 중 하나만 충족하면 100점. 둘 다 채워도 점수는 그대로다.
```

같은 `OrGroup`에 묶인 조건들로, **하나만 채우면 그 그룹은 충족입니다.** 이미 충족된 그룹의 나머지 줄은 `불필요`로 표시됩니다.
게임 전체에서 여왕 엔딩의 전사평가·마법평가 한 곳뿐입니다.

### 플로우 에피소드 — OO
**목표 엔딩에 딸린 에피소드 체인**을 순서대로 보여줍니다.
이번 회차에 뭘 봤고 뭐가 남았는지, 남은 건 어떻게 뜨는지가 한눈에 들어옵니다.

```
플로우 에피소드 — 여왕   이번 회차 2/7   계정 5/7
  ● 이번 회차에 봄   ◐ 계정엔 있음(과거 회차)   ○ 아직 못 봄

  ● 여왕 에피소드 1        스케줄 직후      Pri 4
      조건 자유활동 — 마을 외곽 분쟁을 말로 중재
  ◐ 여왕 에피소드 3        스케줄 직후      Pri 5
      조건 자유활동 — 마수를 혼자 격퇴. 전투 스탯 필요
      참고 현재 힘 0, 민첩 0, 전사평가 0, 공격력 0
  ○ 여왕 에피소드 6        정기 자동        Pri 1
      조건 대공의 편지 — 성 퀘스트 완료가 게이트로 추정 (미검증)

  다음 목표 → 여왕 에피소드 3
    발동 방식 스케줄 직후 · 해당 스케줄을 수행한 직후에만 후보에 오름
    Priority 5 — 같은 트리거의 Pri 0 이벤트가 대기 중이면 계속 밀립니다.
```

- **●** 이번 회차에 이미 본 것 / **◐** 과거 회차에서 본 적 있음(다시보기엔 있음) / **○** 아직 못 봄
- **Pri**(우선순위)는 **낮을수록 먼저** 뜹니다. 3 이상이면 노란색 — 같은 트리거에 Pri 0짜리가
  대기 중이면 계속 밀리므로, 경쟁 이벤트를 먼저 털어야 합니다
- **조건**은 실플레이로 확인된 것만 적혀 있습니다. 확인 못 한 건 `미검증`으로 표시하고
  대신 트리거 의미를 보여줍니다
- **실측** 줄은 실제로 발동한 회차와 안 뜬 회차의 수치 — 임계값의 상한·하한
- **참고** 줄은 그 에피소드가 요구하는 스탯의 현재값 (전투 게이트 확인용)

`run.bat --flow` 로 이 부분만 크게 볼 수 있고, `--target` 을 바꾸면 다른 엔딩 체인이 나옵니다.

### 성 접견

성 NPC 9명을 **실제로 찾아갔는지**를 봅니다.

```
성 접견  5/9명
  NPC           해금 조건         상태      방문
  아르마        없음              접견함    15회
  제스터        매력 50           미접견    —
  린네          예절 150          미접견    —
  밀카 대공     예절 300          접견함    20회

  아직 안 만난 사람  요키, 대마법사, 제스터, 린네
```

- **해금 ≠ 접견.** 스탯이 충분해도 직접 찾아가지 않으면 아무 일도 안 생깁니다
- **성 퀘스트는 접견한 NPC가 줍니다.** 편지가 안 오거나 퀘스트가 없으면 여기부터 확인
- 프린세스 Ep3, 여왕 Ep6·7이 전부 이 라인에 묶여 있습니다

### 자격을 갖춘 엔딩
지금 조건을 전부 충족한 엔딩 목록. Weight가 높은 순이고, 🏆 가 지금 끝나면 나올 것으로 보는 엔딩입니다.

### 자격에 근접한 엔딩
조건이 한두 개만 남은 엔딩과 그 남은 조건. 조금만 더 하면 후보에 끼어들 수 있는 것들이라, 무엇을 **그만둬야** 하는지 판단할 때 씁니다.

### 자격 경쟁
목표 엔딩이 자격을 갖췄을 때만 나옵니다. 목표보다 Weight가 높으면서 자격까지 갖춘 엔딩을 보여 줍니다. 이런 엔딩이 있으면 그쪽이 먼저 나오므로, 그 엔딩의 조건 하나를 일부러 미달로 두어야 합니다.

### 스케줄 등급
등급과 다음 등급까지 남은 점수·횟수.

### 이번 회차 플로우 에피소드
발동한 에피소드 목록. `T1017·P1` 은 트리거 1017, 우선순위 1.

## 알아두면 좋은 규칙

### 엔딩은 자격 체크리스트
엔딩마다 조건이 있고, **조건을 전부 충족한 엔딩만 후보**가 됩니다. 후보가 여럿이면 Weight가 높은 쪽이 유력합니다.

처음에는 조건마다 붙은 점수를 더해 가장 높은 엔딩이 나오는 줄 알았는데 틀렸습니다. 실제 엔딩 기록 57개에 두 가설을 대조하니 「최고점이 이긴다」는 26개, 「전부 충족해야 자격」은 46개를 맞혔습니다. 나머지 11개는 이 규칙으로도 설명하지 못했으므로 예측이 틀릴 수 있습니다.

그래서 "내 엔딩 조건을 채우는 것"만큼 **"Weight가 더 높은 엔딩이 자격을 못 갖추게 하는 것"** 이 중요합니다.

### 스케줄 등급은 횟수가 아니라 누적 성공점수
성공 1회 ≈ 10점. `Edu_*` 계열 공통 임계값은 **42 / 96 / 160 / 234 점**.

| 등급 표기 | D | C | B | A | S |
|---|---|---|---|---|---|
| 내부 값 | 1 | 2 | 3 | 4 | 5 |

A등급(4) = 160pt ≈ 16회, S등급(5) = 234pt ≈ 24회.

### 트리거 코드

| 코드 | 언제 발동 |
|---|---|
| 1010 | 정기 자동 체크 (행상인·점술가·교사방문·청혼 등) |
| 1012 | 편지 수령 |
| 1017 | 스케줄 수행 직후 |
| 2012 | 성에서 퀘스트 완료 보고 |
| 5001 | 축제 우승 |
| 5002 | 수확제 연회 참가 |

**Priority는 숫자가 낮을수록 먼저 발동**하고, 한 번 발동한 이벤트는 대기열에서 빠집니다.
낮은 우선순위 에피소드를 노릴 땐 앞에 대기 중인 이벤트를 먼저 소진시켜야 합니다.

## 다른 사람도 쓸 수 있나요

**네.** 복호화 키는 Steam64 ID로부터 계산되며, 세이브 폴더 이름이 곧 Steam64 ID이므로
프로그램이 알아서 감지합니다. 그냥 폴더째 복사해서 주면 됩니다.

폴더 구조가 특이해서 자동 감지가 안 될 경우에만 직접 지정하세요.

```
run.bat --steamid 76561198xxxxxxxxx
```

## 문제가 생기면

**`run.bat` 이 안 켜지거나 창이 바로 닫힐 때** — 터미널에서 직접 실행하면 에러가 보입니다.

```
cd "<이 폴더의 경로>"
py pmk.py
```

**`Python not found`** — 터미널에서 `winget install -e --id Python.Python.3.12` 실행 후 창을 새로 엽니다.

**`세이브 폴더를 찾지 못했습니다`** — 기대 경로는
`%USERPROFILE%\AppData\LocalLow\GEAR2\PrincessMakerKaren\Save\<steamID>\` 입니다.
